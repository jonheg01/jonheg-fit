# JonHeg Fit

Training, match and drill tracking for USPSA and 3-Gun shooters. Static PWA on GitHub Pages; backend is the Supabase edge function fit-api (project pah-crm). jonheg01/jonheg-fit serves jonheg.fit and jonheg01/brandon-jonheg-fit serves brandon.jonheg.fit from the same code; only CNAME differs. Deploys go through the fit-site-deploy edge function.
